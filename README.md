# Pomodoro Timer 🍅

A simple and customizable Pomodoro timer built with Python and Tkinter. This application helps users manage their work sessions and breaks effectively using the Pomodoro technique.

## Features
- **Customizable Durations**: Set your preferred durations for work sessions, short breaks, and long breaks.
- **Progress Tracking**: View the number of completed Pomodoro cycles.
- **Dynamic Backgrounds**: Enjoy a refreshing change in background color every few seconds.

## Installation

### Prerequisites
- Python 3.x installed on your system.
- The `tkinter` library (usually included with Python).

### Steps
1. Clone or download the project to your local machine.
2. Navigate to the project directory.
3. Install any required dependencies using:
   ```bash
   pip install -r requirements.txt
   ```

## Usage
To start the application, run:
```bash
python main.py
```

## How to Use
1. **Set Durations**: Use the input fields to define custom durations for work, short breaks, and long breaks.
2. **Save Settings**: Click "Save Durations" to apply your changes.
3. **Start Timer**: Click "Start" to begin your session.
4. **Track Progress**: View completed cycles in the progress label.
5. **Reset Timer**: Click "Reset" to reset the timer to the saved durations.
